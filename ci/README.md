# CI-voorbeeld

`test.yaml` is een GitHub Actions-voorbeeld. Het is niet actief: de GitHub-aanmelding
bij deze import had geen `workflow`-scope. Een bevoegde maintainer kan het bestand
naar `.github/workflows/test.yaml` kopieren. De workflow is nog niet uitgevoerd.
De adapter- en bibliotheektests zijn wel lokaal uitgevoerd: 16 adaptertests + 225 protocoltests + 10 tests met echte HA-klassen geslaagd.
